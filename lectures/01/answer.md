# 第1回 解答

## 演習

- 講座に固有の質問へのモデルの回答：Gemini API キーを設定していないため、実際のモデルへの質問は未実行。回答を推測して記載しない。
- 用語集との比較：モデルの回答がないため未実施。
- 表示できたトークン数（入力 / 出力）：実 API の値は未計測。`app/ask.py` に `usage_metadata` の入力・出力トークン数を表示する処理を追加し、テスト用の応答で表示を検証した。

## 宿題

- 取り組んだレベル：実装
- やったこと：`app/ask.py` に `--chat` を追加。同じチャットオブジェクトに最初の質問と追加質問を順に渡し、空行で終了する。指定しない場合は従来の単発質問を維持した。応答に利用量が含まれる場合は入力・出力トークン数も表示する。
- 結果：ローカルの Python 3.12.14、`uv sync --frozen` で配布の固定依存を導入し、`uv run pytest -q` で **12 passed**。追加したテストでは、2 回の質問が同じチャットに渡り、2 回目の模擬応答に最初の質問が含まれることを確認した。実際の Gemini API 呼び出しと実トークン数の計測はしていない。
- 気づき・疑問：単発呼び出しを繰り返すだけでは文脈がつながらず、会話セッションを保持する必要がある。実 API の応答品質やレート制限は今回の模擬テストでは判断できない。
